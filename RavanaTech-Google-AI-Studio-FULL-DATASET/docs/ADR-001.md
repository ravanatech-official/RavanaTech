# ADR-001 — One Reception Orchestrator

**Decision:** Replace multiple receptionist/avatar/quotation components with one orchestrator.

**Reason:** The supplied code has several overlapping components with duplicated voice, flow, quotation and reception responsibilities. A single state machine reduces dead ends, conflicting UI, repeated questions and maintenance cost.

**Consequence:** The public site has one journey state; independent browsing remains available but is no longer the default way a new visitor discovers information.
