# RAVANA TECH — PRICING TRUTH DATA

## Current safe public rule
The newer production `servicesData.ts` describes service pricing as **Custom Quotation by Scope**.

## Conflicting legacy pricing exists
Older prototype/legacy files contain multiple different price ranges, including package prices and service-specific prices. Those figures conflict with one another and were not established as current verified pricing.

Examples of legacy values found during audit include:
- starting-price wording around Rs. 18,000 in an older project knowledge snapshot;
- multiple package ranges such as Rs. 20,000–28,000, Rs. 32,000–45,000, Rs. 45,000–65,000 and Rs. 25,000–38,000;
- older service-specific ranges such as Rs. 35,000–45,000, Rs. 45,000–55,000, Rs. 30,000–40,000 and Rs. 50,000–75,000.

These are **legacy reference values only** and must NOT be presented to visitors as current Ravana Tech pricing.

## AI response rule
If exact current pricing is not explicitly approved in the active Truth Registry:

No invented price. No calculated quote presented as binding.
