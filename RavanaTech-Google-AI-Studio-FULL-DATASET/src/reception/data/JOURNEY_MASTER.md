# RAVANA TECH — JOURNEY MASTER DATA

## Primary experience
Virtual Reception / Digital Front Desk

## First five intents
1. I need something new
2. I already have a website
3. Show me what you can build
4. I'm not sure what I need
5. I want to discuss my project / quotation

## Journey rule
Every step offers up to five contextually relevant choices. The next question must depend on the current context and previous answers. Do not turn the experience into a rigid survey.

## Outcome rule
A completed journey should produce useful value:
- understood need
- concise recommendation
- relevant proof/demo/service
- project brief when appropriate
- next action: WhatsApp, call, inquiry, relevant demo, or human handoff.

## Path-specific source
The detailed bilingual flow is implemented in the supplied `flowCatalog.ts`. That file is included beside this document for AI Studio reference.

## Important architecture constraint
Normal public spaces such as services, projects, about, blog and contact remain available, but they are supporting knowledge spaces, not the primary first-visit navigation model.
