1. COOKIE USAGE & CLIENT STORAGE ARCHITECTURE

Unlike bloated corporate portals that deploy dozens of third-party advertising, ad-tech, and fingerprinting trackers, Ravana Tech operates under a Zero Invasive Tracking Pledge.

  • Strictly Necessary Technical Storage: We use browser localStorage solely to remember your UI state (e.g. active screen, dark theme settings, and CV editor drafts). This data never leaves your personal device.
  • Performance Telemetry: Anonymized server-side request metrics (load timing, status code, response time) are captured strictly for server health diagnostics.
  • Zero Behavioral Retargeting: We do not place third-party marketing cookies, cross-site trackers, or behavioral beacons on this website.

2. SERVER DEFENSE & STORAGE ISOLATION

Protected Ingestion Gateways: Inquiry data transmitted through our web form or REST API is validated, stripped of malicious injection strings, and written to secured storage.
  • Directory Traversal Shield: Internal database files (data/leads-db.json), system scripts, and server configuration files are blocked from public web retrieval via strict Express route guards.
  • Rate Limiting: Automatic rate-limiting prevents automated spam bots from flooding the server or probing endpoints.
  • Firestore Rules: Cloud Firestore documents enforce write-only creation rules. Unauthorized public reading or modification is denied at the database rule layer.

3. DATA PURGING & CLIENT PURGE ON DEMAND

We do not hoard inactive data. If you submit a project inquiry and choose not to proceed with development, you can request immediate removal of your record by sending a message with your reference ID to hello.ravanatech@gmail.com.

Upon receiving an erasure request, the corresponding record is deleted from both our active database and backup registers within 48 business hours.
